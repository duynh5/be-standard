# Senior Backend Engineering with Go

This repository is a self-paced, comprehensive path from beginner to competent
senior backend engineer. Go is the reference language, while the architecture,
data, API, security, reliability, and delivery practices transfer to other common
backend stacks.

All learning material is in one flat directory. Read the numbered files in order,
or start at the first topic whose completion evidence you cannot already produce.
There is no daily or weekly schedule.

The chapters use one evolving Order API instead of disconnected toy examples.
Progress is evidence-based: implement the behavior, make its failure mode happen,
pass the required checks, and explain the tradeoff. Reading alone is not completion.
